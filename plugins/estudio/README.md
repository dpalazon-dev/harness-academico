# Estudio

Plugin de núcleo del fork `sistema-comun`. Guarda planes de estudio entre sesiones, convierte el resultado del sondeo en unidades propuestas y lleva el módulo de evaluación (respuesta congelada, autoevaluación y repaso espaciado), que adapta de StudyHarness la calibración, la escalera de repaso y el orden de la cola; véase `THIRD-PARTY.md`.

Diseño: las decisiones están en `docs/adr/` y las diferencias con LearnHarness en `docs/sistema-comun/divergencias.md`.
